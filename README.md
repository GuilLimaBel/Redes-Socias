# Projeto de Banco de Dados

**Nome do Projeto: Sistema de Rede Social**  
**Equipe de Desenvolvimento: Guilherme**

## 1. Visão Geral do Sistema (Escopo)

O sistema tem como objetivo desenvolver uma rede social onde os usuários possam criar e compartilhar postagens, além de interagir com os conteúdos publicados. As postagens poderão conter textos, músicas, mídias e curtidas, enquanto os comentários permitirão interações por meio de textos, elogios e reações.

## 2. Requisitos Funcionais (RF)

**RF01**: O sistema deve gerenciar o cadastro dos usuários, as informações necessárias são:
-   ID
-   Nome
-   E-mail
-   Senha

**RF02**: O sistema deve permitir que o usuário realize postagens contendo as seguintes informações:
-   ID
-   Texto
-   Música
-   Mídia
-   Curtidas

**RF03**: O sistema deve associar cada postagem ao usuário responsável pela sua realização.

**RF04**: O sistema deve permitir que uma postagem possua comentários.

**RF05**: O sistema deve permitir que os comentários sejam registrados contendo as seguintes informações:
-   Texto
-   Elogios
-   Reação

**RF06**: O sistema deve associar cada comentário à postagem correspondente.

**RF07**: O sistema deve permitir que um usuário realize várias postagens.

**RF08**: O sistema deve permitir que uma postagem possua vários comentários.

**RF09**: O sistema deve permitir que os usuários visualizem as postagens e seus respectivos comentários.
